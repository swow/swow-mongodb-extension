# Repository Conventions

- Write documentation and code comments in English.
- Preserve upstream comments, licensing and formatting. Keep fork changes focused; do not reformat imported source or tests.
- Follow Swow Git conventions: concise imperative English commit titles without Conventional Commit prefixes, linear history, `ci` for development and `develop` for releases.
- Use strict types and the shared Swow PHP coding style for new PHP tooling.
